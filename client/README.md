# AI Resume Builder

An AI-powered Resume Builder web application where users can create, edit, preview, and download professional resumes through an interactive and responsive interface.

## Features

- User Authentication & Authorization
- AI-based Resume Generation
- Resume Editing and Live Preview
- Download Resume as PDF
- Multiple Resume Templates
- AI-based Skill Suggestions
- Responsive Design
- Backend API Integration
- File Upload Support
- Dark Mode Support

## Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- PostgreSQL

## Project Structure

```bash
AI_RESUME_BUILDER/
│
├── client/   # Frontend
├── server/   # Backend
```

## Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/AI_RESUME_BUILDER.git
```

### Frontend Setup

```bash
cd client
npm install
npm run dev
```

### Backend Setup

```bash
cd server
npm install
npm start
```

## Environment Variables

Create a `.env` file inside the `server` folder and add:

```env
DATABASE_URL=your_postgresql_connection
JWT_SECRET=your_secret_key
```
