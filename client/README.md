# AI Resume Builder

An AI-powered Resume Builder web application developed using the MERN stack. Users can create, edit, and manage professional resumes with an interactive and responsive interface.

## Features

- User Authentication
- AI Resume Generation
- Resume Editing and Preview
- Responsive Design
- Backend API Integration
- File Upload Support

## Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- PostgresQL

## Project Structure

```bash
AI_RESUME_BUILDER/
│
├── client/   # Frontend
├── server/   # Backend
```

## Installation

### Clone Repository

```bash
git clone https://github.com/yourusername/AI_RESUME_BUILDER.git
```

### Frontend Setup

```bash
cd client
npm install
npm run dev
```

### Backend Setup

```bash
cd server
npm install
npm start
```

## Environment Variables

Create a `.env` file inside the `server` folder and add:

```env
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
```
